# UI v0.2 — Minimal

Dirección visual aprobada para explorar:

- estética minimalista inspirada en herramientas de producción como Ableton;
- tema claro y oscuro;
- esquinas apenas redondeadas;
- casi sin sombras;
- bordes finos y jerarquía basada en tipografía;
- botón DISPARAR protagonista pero plano;
- sonidos/referencias mostrados como lista técnica, no como chips;
- setlist con fila activa marcada por una línea de acento;
- títulos largos: hasta dos líneas con tamaño adaptable antes de recurrir a cualquier scroll.

El prototipo interactivo está en `prototype/index.html`.
