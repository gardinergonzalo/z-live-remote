# Z Live Remote — iOS

Base de la app nativa para iPhone/iPad construida con SwiftUI.

## v0.1

Esta primera base trabaja con datos simulados y deja resuelto el flujo visual principal:

- PREPARADA
- DISPARAR
- REPRODUCIENDO
- STOP con pulsación prolongada
- Anterior / Siguiente sin disparar
- Setlist
- Nombre de canción adaptable a una o dos líneas
- Lectura del formato `Canción | Sonido 1 | Sonido 2 | ...`

## Próximo paso

Conectar el ViewModel a la capa de transporte real Ableton ↔ Mac ↔ iPhone/iPad sin cambiar la interfaz.
